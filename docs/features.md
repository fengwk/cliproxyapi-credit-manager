# 管理功能与边界

插件提供 CM 管理界面、当前账本和客户自助查询。执行、上游账号选择、重试和会话亲和
始终由 CPA 负责；插件不接管执行链。

## 功能

| 能力 | 当前行为 |
| --- | --- |
| CPA 视觉与主题 | CM SVG 标识，white/light/dark/auto，卡片/表格/弹窗，桌面与移动端 |
| 登录保持 | 默认当前标签会话保持；显式记住后跨页面恢复；登出清理 |
| 趋势 | 本地 ECharts，请求/执行、Token 五桶、执行费用/人工补记；UTC 时/日/自然月 |
| 单位与币种 | 原始/k/万/m；USD/CNY 手动或显式刷新参考汇率，精确文本，换算不影响计费 |
| Key 约束 | 总/日/周/月额度、并发、过期、模型白名单及模型 Token 限额 |
| 客户自助查询 | 自己的额度/用量/趋势/请求快照，无需管理密钥，无跨 Key 查询 |
| 请求日志 | 请求 Header/Body 查看，敏感字段脱敏、懒加载、请求归属校验 |
| 日志生命周期 | 请求体 gzip，默认 24h；容量驱逐；历史默认 3 UTC 日历月；增量回收 |
| CPA 执行链 | 不注册 Executor/Router/Scheduler，不覆写粘性；原生重试/账号选择归 CPA |
| 版本比较 | 注册版本不附加提交哈希；诊断保留构建提交 |
| 概览分析 | 全量筛选集的模型请求/Token/费用占比、成本/缓存/测量吞吐/延迟排行；不使用当前页冒充全量 |
| 定价规则 | exact/glob/regexp、优先级、上下文/服务档位及按图计费；准入冻结完整费率，后改规则不影响旧请求 |
| 模型价格目录 | 固定 models.dev 源与回退源、限时限量缓存、过期标识、分页预览与明确确认导入；不后台改价 |
| Key 管理 | 新 Key AES-GCM 可恢复密文、显式查看并审计、软删除、总/日/周/月额度基线重置 |
| 调用方与审计 | caller 仅归属元数据；Key/价格/人工核账等管理操作与审计同事务 |

## 职责之外

以下能力不属于插件职责，不存在隐藏开关：

- 无确认的后台自动改价。目录刷新只更新参考目录，不修改系统费率。
- 导入或迁移其它账本格式。首次运行使用空目录，一次性创建完整当前结构；同格式可重开，
  其它格式被拒绝，不会被修补、转换或静默删除。请求只有一份必需的冻结价格快照，
  每把 Key 都保存可验证的 AES-GCM 密文，不存在历史费率或 HMAC-only 回退模式。
- caller 级别的鉴权/调度/并发接管。调用方停用只是元数据，不改变 Key 鉴权或会话身份。
- 按账号并发控制、执行器接管、账号排除与调度覆写。插件只负责客户端鉴权、额度准入与通知
  记账，不注册执行/路由/调度能力，也不发起任何宿主模型执行回调。

### 计费语义

- 默认仍为请求模型的精确价格。规则按优先级降序，同级 exact/glob/regexp、规则 ID
  排序；精确价格表为优先级 0 的 exact 候选，同级显式 exact 规则优先。
- 禁用的获胜规则直接拒绝，缺价格直接拒绝；基础费率显式 0 为免费。
  档位桶费率 0 为继承；思考费率缺省继承输出，显式 0 为免费。
- 上下文门槛按实际输入（含缓存读写）选择；服务档位优先于上下文档位，
  上游明确报告 default/auto 会覆盖请求时的 priority，而不是错误地继承它。
- PluginAPI 8.0.30 没有实际出图数。按图计费只能在成功且计量可信的生命周期，
  按冻结的请求图片数计一次（默认 1，显式只支持 1..32，越界拒绝而不截断）。
  无可信成功证据时保留待定，不将其当作免费；无法核对上游实际出图数与请求数的差异。
- 重置只记录所选周期的 money 与模型 Token 计数基线。`spent_micro_usd` 是终身账本，
  `quota_used_micro_usd` 及日/周/月 used 字段是重置后的额度占用基线；历史与未决请求不清除，
  之后收到的迟到扣费仍计入原请求所属期间。
- 准入不预估、不预留、不占用金额：额度是“实际已用”的软限制，真实用量（包括并发超额）
  一律足额入账；未决用量可见但不冻结任何金额，也不阻塞后续准入。
- Key 的密文与 pepper 都须保护。管理鉴权可解密新 Key，不能把此功能称为防止整目录泄露的保险箱；
  明文不进入普通列表、审计、URL 或前端持久存储。

## 边界

- 不是响应 Header/Body 或最终上游原始 HTTP 报文抓包。
- gzip 压缩保留与到期删除已经存在；没有“到期后永久压缩归档”。
- 捕获默认关闭，非完整 DLP；空间回收有界，清理失败通过健康接口报告。
- 客户 Key 与管理密钥都不进入 URL/Cookie；记住密钥会增加同源 XSS 风险，
  共享设备上应取消记住并登出，不应把记住密钥称为加密保险箱。

## 可复用验收

```sh
make test
make race
make static
CHROME_BIN=/usr/bin/google-chrome-stable make browser
```

真实 CPA 8.0.30 + 编译后的原生库 + 环回上游的验收命令、必需工具与隔离说明，
见 `../tests/integration/README.md`。浏览器测试不得在缺少图表或用例失败时跳过报绿。
