# 管理功能与边界

插件提供 CM 管理界面、用量日志与参考成本展示、客户自助查询。执行、上游账号选择、
重试和会话亲和始终由 CPA 负责；插件不接管执行链。价格和美元预算只展示，
不参与请求准入。

## 功能

| 能力 | 当前行为 |
| --- | --- |
| CPA 视觉与主题 | CM SVG 标识，white/light/dark/auto，卡片/表格/弹窗，桌面与移动端 |
| 登录保持 | 默认当前标签会话保持；显式记住后跨页面恢复；登出清理 |
| 趋势 | 本地 ECharts，请求/执行、Token 五桶、已定价执行小计与未定价执行数；UTC 时/日/自然月 |
| 单位与币种 | 原始/k/万/m；USD/CNY 手动或显式刷新参考汇率，精确文本，换算不影响成本计算 |
| Key 约束 | Token 总/日/周/月配额、并发、过期、模型白名单及模型 Token 限额；四个美元字段仅为展示预算 |
| 客户自助查询 | 自己的预算/Token 用量/趋势/未定价执行数/请求快照，无需管理密钥，无跨 Key 查询 |
| 请求日志 | 请求 Header/Body 查看，敏感字段脱敏、懒加载、请求归属校验 |
| 日志生命周期 | 请求体 gzip，默认 24h；容量驱逐；历史默认 3 UTC 日历月；增量回收 |
| CPA 执行链 | 不注册 Executor/Router/Scheduler，不覆写粘性；原生重试/账号选择归 CPA |
| 版本比较 | 注册版本不附加提交哈希；诊断保留构建提交 |
| 概览分析 | 全量筛选集的模型请求/Token/已定价成本占比、成本/缓存/测量吞吐/延迟排行；不使用当前页冒充全量 |
| 定价规则 | exact/glob/regexp、优先级、上下文/服务档位及按图价格；查询时按实际执行模型匹配当前价格，改规则后历史重算 |
| 模型价格目录 | 固定 models.dev 源与回退源、限时限量缓存、过期标识、分页预览与明确确认导入；不后台改价、不自动关联别名 |
| Key 管理 | 新 Key AES-GCM 可恢复密文、显式查看并审计、软删除、Token 总/日/周/月基线重置 |
| 调用方与审计 | caller 仅归属元数据；Key/价格/Token 基线重置等管理操作与审计同事务 |

## 首次使用

新账本没有预置价格。价格不是分发 Key 的前提：可以先创建并分发 Key；
未配价不会阻止调用；没有可用价格时，执行成本显示为未定价。禁用规则会被跳过，
其余生效规则或价格表仍可提供价格。Key 权限和 Token 等限制保持生效。
如需成本展示，在「价格规则」为用量日志中的实际执行模型 ID 配置或确认导入价格，
再用「价格预览」核对匹配。Key 的「全部模型」权限不代表有价格或免费。
CPA 自定义别名不会自动换成目录里的模型名；计价使用日志中的实际执行模型，而不是别名。

参考目录优先读取 models.dev，失败时尝试 models.opencode.ai，缓存 6 小时；
读取或刷新目录不会写入价格规则，也不会在推理/准入路径联网。
导入草稿为优先级 10 的 exact 规则，确认保存后生效。
调用方仅是可选的归属元数据；显示名称必填，ID 可由服务端生成。

## 职责之外

以下能力不属于插件职责，不存在隐藏开关：

- 无确认的后台自动改价。目录刷新只更新参考目录，不修改系统费率。
- 导入或迁移其它账本格式。首次运行必须使用空目录，单条 DDL 一次性创建完整当前结构
  （`PRAGMA user_version=2`）；同格式可重开，其它格式（包括 v0.1.5 的 format 1）
  被拒绝且不被修改，不会被修补、转换或静默删除。需要新空 `data_dir`，原库保留备份，
  不建议直接清库。不存在价格/金额快照或旧字段回退。每把 Key 都保存可验证的
  AES-GCM 密文，不存在 HMAC-only 回退模式。
- caller 级别的鉴权/调度/并发接管。调用方停用只是元数据，不改变 Key 鉴权或会话身份。
- 按账号并发控制、执行器接管、账号排除与调度覆写。插件只负责客户端鉴权、Token 配额准入
  与用量通知记录，不注册执行/路由/调度能力，也不发起任何宿主模型执行回调。

### 成本语义

- **价格和四个美元 budget 只展示，不限制请求。** KeySpec 的 `quota_micro_usd`、
  `daily_micro_usd`、`weekly_micro_usd`、`monthly_micro_usd` 字段名保留，但表示预算；
  `0` 为未设置。Key 没有 `spent_micro_usd`/`quota_used_micro_usd` 等永久金额字段。
- **查询时定价**：每条执行用 CPA UsageRecord 的实际 `usage.model`（完整精确 ID）、
  规范化五桶 Token 和 `service_tier` 匹配当前价格。请求别名、`RequestedModel`、
  `ResponseModel` 不用于猜价；请求时也不冻结费率。改价/加价/删价后，已保留日志
  在下一次查询立即重算。
- 规则按优先级降序，同级 exact/glob/regexp、规则 ID 排序；精确价格表为优先级 0 的
  exact 候选，同级显式 exact 规则优先。`disabled` 规则只是不参与价格匹配，
  不是模型权限黑名单，不会拒绝请求。
- **缺价、不完整/不可信用量、整数溢出、`per_image` 但缺少真实出图数量**时，
  `Usage.cost_micro_usd` 为 `null`，并计入 `Summary.unpriced_executions`；
  summary 成本只是已定价执行的小计。基础费率显式全零且用量完整时是**已定价的 0（免费）**，
  与未知的未定价明确区分。档位桶费率 0 为继承；思考费率缺省继承输出，显式 0 为免费。
- 上下文门槛按实际输入（含缓存读写）选择；服务档位优先于上下文档位，
  上游明确报告 default/auto 会覆盖请求时的 priority，而不是错误地继承它。
- PluginAPI 8.0.30 的 UsageDetail 没有真实出图数量。按图价格目录/规则/预览可以保留，
  但日志无法证明实际出图数，因此 `per_image` 执行的费用必须为 `null`（未定价），
  不能用请求里的图片数冒充实际产出。
- `POST /api/reset-tokens` 仅重置所选 Key/周期的 **Token 有效用量基线**，
  不修改日志、派生费用或美元预算；历史与未决请求不清除。旧 `/api/reset-spend`
  与 `/api/resolve` 均不再注册。
- 准入不读价格、不预估、不预留、不占用金额：Token 配额是“实际已用”的软限制，
  真实 Token 用量（包括并发超额）一律足额记录；未决用量可见但不冻结任何金额，
  也不阻塞后续准入。完整但未定价的用量可正常 `settled`；价格不改变生命周期状态。
- 成本只反映仍在本地保留的日志和所选时间段，不声称永久全历史。查询会为所选执行流做
  一次额外的精简扫描；内存随分组/分页大小增长，不是 Observer 式长期预聚合。
  实际数字是基于本地参考价格的用量成本，不等同上游最终账单。
- Key 的密文与 pepper 都须保护。管理鉴权可解密新 Key，不能把此功能称为防止整目录泄露的保险箱；
  明文不进入普通列表、审计、URL 或前端持久存储。

## 边界

- 不是响应 Header/Body 或最终上游原始 HTTP 报文抓包。
- gzip 压缩保留与到期删除已经存在；没有“到期后永久压缩归档”。
- 捕获默认关闭，非完整 DLP；空间回收有界，清理失败通过健康接口报告。
- 客户 Key 与管理密钥都不进入 URL/Cookie；记住密钥会增加同源 XSS 风险，
  共享设备上应取消记住并登出，不应把记住密钥称为加密保险箱。
