# v0.1.3

修复通过 CPA 插件商店安装时，因宿主注入 `store` 配置块导致严格校验报错、插件未能成功注册生效的问题。
宿主要求仍为 **CLIProxyAPI v8.0.30、ABI 1 / RPC schema 6**。

## 修复内容

- **兼容 CPA 插件商店注入的 `store` 配置段**：
  在 `Config` 结构体中添加 `Store yaml.Node` 字段定义，避免插件严格校验模式（`KnownFields(true)`）将 CPA 自动添加的商店元数据误判为非法未知字段，从而解决在 CPA 商店一键安装后插件状态显示“未生效 / 未注册 / 已配置”的问题。
- **补齐商店契约与生命周期单测**：
  新增单元测试，确保携带 `store` 节点的配置能够正确通过解析并在生命周期内完成注册与重配。
