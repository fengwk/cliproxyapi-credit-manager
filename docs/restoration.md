## 不应误称为完整原版兼容

以下原版能力当前仍**没有移植**，不是已实现功能或隐藏开关：

- 无确认的后台自动改价。目录刷新只更新参考目录，不修改系统费率。
- 原版独立项目数据库的直接迁移。本项目既有账本采用增量事务迁移，保留旧费率列、
  请求/执行/计数器；旧 HMAC-only Key 无法反推出明文，只能轮换后启用查看。
- 原版 caller 级别的鉴权/调度/并发接管。调用方停用只是元数据，不改变 Key 鉴权或会话身份。
- 原版按账号并发控制、执行器接管、账号排除与调度覆写。这些不能为了视觉复原
  再次混入普通请求链。可选预热仍默认关闭，使用宿主显式指定凭据的回调。

本轮对齐上述不接管 CPA 执行链的功能，**并非原版全部功能等价迁移**。

### 财务兼容语义

- 默认仍为请求模型的精确价格。规则按优先级降序，同级 exact/glob/regexp、规则 ID
  排序；精确价格表为优先级 0 的 exact 候选，同级显式 exact 规则优先。
- 禁用的获胜规则直接拒绝，缺价格直接拒绝；基础费率显式 0 为免费。
  档位桶费率 0 为继承；思考费率缺省继承输出，显式 0 为免费。
- 上下文门槛按实际输入（含缓存读写）选择；服务档位优先于上下文档位，
  上游明确报告 default/auto 会覆盖请求时的 priority，而不是错误地继承它。
- PluginAPI 8.0.30 没有实际出图数。按图计费只能在成功且计量可信的生命周期，
  按冻结的请求图片数计一次（默认 1，显式只支持 1..32，越界拒绝而不截断）。
  无可信成功证据时保留待定，不将其当作免费；无法核对上游实际出图数与请求数的差异。
- 重置只记录所选周期的 money 与模型 Token 计数基线。`spent_micro_usd` 是终身账本，
  `quota_used_micro_usd` 及日/周/月 used 字段是重置后的额度占用；历史与未决 hold 不清除，
  之后收到的迟到扣费仍计入原请求所属期间。
- Key 的密文与 pepper 都须保护。管理鉴权可解密新 Key，不能把此功能称为防止整目录泄露的保险箱；
  明文不进入普通列表、审计、URL 或前端持久存储。

## 边界

- 不是响应 Header/Body 或最终上游原始 HTTP 报文抓包。
- gzip 压缩保留与到期删除已经存在；没有“到期后永久压缩归档”。
- 捕获默认关闭，非完整 DLP；空间回收有界，清理失败通过健康接口报告。
- 客户 Key 与管理密钥都不进入 URL/Cookie；记住密钥会增加同源 XSS 风险，
  共享设备上应取消记住并登出，不应把记住密钥称为加密保险箱。
