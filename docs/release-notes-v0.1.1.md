# v0.1.1

修复请求详情布局：长价格说明和人工补记独占整行，模型字段的标签与数值上下排列，
避免长标签把数值挤成逐字竖排、导致请求卡片异常拉长。移动端使用单列布局。

- 新增真实浏览器字段宽度与卡片高度回归检查，覆盖桌面和 390px 窄屏。
- 不修改鉴权、价格、账务、数据结构、调度或预热行为。
- 宿主仍为 CLIProxyAPI v8.0.30，ABI 1 / schema 6。
- 提供 Linux amd64、Linux arm64、macOS arm64 原生库和 SHA256 清单。

从 v0.1.0 升级：停止 CPA，备份整个数据目录，用新库覆盖同名文件，保留原数据目录
与 `pepper`，重新启动。不要删除数据库或重新创建客户端 Key。

安装、安全部署和保证边界见 [README](../README.md) 与 [运维手册](operations.md)。
