输入管理密钥

管理密钥仅保留在当前页面的内存中，用于向管理 API 发送 Authorization 请求头。 界面不会把密钥写入 localStorage、sessionStorage、Cookie 或 URL，刷新页面后需重新输入。

连续 5 次提交错误的密钥会导致当前客户端 IP 被临时封禁约 30 分钟，因此本界面不会自动重试登录； 请确认密钥正确后再提交。

趋势

请求明细

价格一律以「微美元 / 每 100 万 tokens」的整数保存（1 USD = 1,000,000 微美元），界面同时给出等值美元换算供核对，不做浮点换算。

本页只读取 CPA 的凭据列表与插件额度接口，不修改上游凭据、不导入原生密钥、不发起 OAuth 流程。 额度是否可用完全取决于每个凭据自身上报的能力，未上报时如实显示为不支持。

其他字段

credit-manager · 管理界面为静态页面，所有数据实时从管理 API 读取。
